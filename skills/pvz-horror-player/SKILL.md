# PVZ 恐怖版 AI 游玩

本技能随 [PVZ 恐怖版 AI Bridge](../../README.md) 提供。安装见 [INSTALL_FOR_AI.md](../../INSTALL_FOR_AI.md)。游戏为 Windows PVZ-Scared 1.0.1，桥接接口 0.2.2，默认本机端口 47633；不适用于杂交版、生存或娱乐模式。

## 首次使用

先确定唯一控制者。已有宿主/runner 操作时沿用它的入口，不再建立输入控制器、不抢占。无宿主则运行项目 `start.cmd`；游戏已开时用 `scripts/launch.ps1 -PidToAttach <实际PID>`。安装配置用 generated/mcp.json；运行 token 从项目 runtime/connection.json 读取，不向用户或日志输出。

优先使用已注册 MCP 的 `pvzh_*` 工具；缺少 MCP 且你明确作为唯一控制者时可用项目 `scripts/client.py` 的持久 `HorrorClient`。开始读 capabilities、observe、menu，再按当前现场 take_control。具体参数见 [接口参考](references/api.md)。

正常代玩保留原生费用、冷却和胜败规则。不要修改游戏文件、存档或 profile 来跳过限制。购物、金币消费、解锁和 test_assist 作弊均需当前会话明确授权；本项目的历史验收不提供授权。

## 规划与执行

首次规划前读取本技能战术要点及 [图鉴机制](references/almanac-tactics.md)。出现新种类或能力疑点再按名字查，不每个动作重读整篇。

- selection 从当前 cards 选卡并 start_battle；running 根据当前行列、费用、可用性和敌情操作。行列从 1 开始。
- 卡片、实体、太阳、菜单与奖励使用最新观察中的字符串 ID；battle_id 随场景变更，不能跨关复用。
- plant 支持 bank、conveyor、falling 卡。shovel 用植物 entity_id，move_plant 用实体和目标格，interact 支持实体、格子或世界坐标。
- `ok=true` 是接口成功；`result.status` 才是动作结果。Committed 不代表击杀、存活或入账。普通动作执行一次，从直接回包或正常下一次观察继续，不重复证明同一业务状态。
- rejected_by_game 后根据当前现场换合法目标或等原生冷却；超时/断线的未知结果不重放。购买先查持久 purchase_receipt，pending/unknown 不能换 ID 再买。
- 只收 NormalSun、SmallSun、TinySun；关闭宽泛 auto_collect。红光默认禁收，特殊例外必须有当前关卡证据、用户授权及接口支持。
- 图鉴、原生设置、难度、速度和暂停按用户意图使用。F8/F9 停止锁不能自行解除，只有玩家按 F10 可恢复。

## 剧情与续关

菜单用当前 menu_id/action_id，结合 texts 理解弹窗。日记正文按 PageBodyColumn1、PageBodyColumn2 顺序阅读；若用户要求朗读，需要播放端实际播完才翻页。没有播放能力就报告限制，不假装播过。用户对剧情阅读的偏好优先，不自动 Skip。

胜利物品可能在 phase=running 出现；尾波清场或 victory 时读 rewards，collect_reward 后按原生菜单续关。只有真实事件卡出现才 choose_event。终关“Z公司档案”3 页依次 NextButton/FinishButton，结束后关闭章节地图再回主菜单。原版主菜单 Event 是固定“暂未解锁”占位，不反复点击等待。

基础 `scripts/play_story.py` 仅作策略示例，不保证处理所有感染、友伤、免疫或剧情阅读需求；不要与 MCP 控制者并行运行。

## 停止与交还

结束时 release_control。同一回包中 selection_released=true、controlled=false、auto_collect=false、held_os_inputs=0 是释放凭据；只取消 AI 自己的原生选择。

release_blocked 时保留宿主与独占连接，等恢复或正常关闭游戏，不能强杀/清锁/启动第二控制器。示例 runner 的独立 evidence 目录写 stop.request 可在循环边界停止；停止宿主写 runtime/stop.request。更新部署在交还、native_selection=0 且宿主停止后进行；纯离线编辑保持健康控制器运行。

## 战术要点

- 依据[图鉴战术与操作禁忌](references/almanac-tactics.md)，不套原版/杂交版。当前现场与用户最新要求优先于旧技能文字；费用、冷却、免疫、可吞名单和范围按现有证据，不补猜。
- **先救场，再补有效防线/输出，再发展经济。** 按观察→规划→提交延迟、敌人移动和植物触发时间选落点；预计下一轮来不及就现在行动，不额外观察拖延。高血量移动敌人不能默认一株射手能及时打死，提前有效阻挡；近端漏怪优先于远处母体，不临敌补慢射手/未成熟雷。碾压、穿越、秒吃和免疫敌人另按机制，不强用墙。
- **手套优先真正有收益的调度。** tools中Glove就绪且来源安全/移后仍能守住才搬，不拆受压路唯一防线。优先近端救场→缺防母体的坚果或有效清除→真正空火力路的闲置/富余输出。调射手也要估计剩余接敌时间能否打完目标血量；能命中不等于来得及，近端才搬不能替代提前阻挡/就绪清除。按当前entity_id、方向、接触距离及延迟选合法位；不假定移动重置血量、吞噬容量或冷却。现有火力能及时处理就不搬，不为整齐反复消耗共享冷却。
- **母体缺防立即调墙或清除。** 闲置坚果可安全调入就提前调，否则新种；都来不及时用当前就绪、可支付且能触发的窝瓜、炸弹、有效吞噬或可确认成熟雷，不只等墙/补葵。母体死后仍清遗留虫。坚果尽量从右数第3列（columns-2，9列为第7列）；已被敌人越过、不合法或感染危险时选真正能拦截的位置。
- **腐烂坚果有伤害，食人花不替代坚果。** `SarcomaWallnut` 受啃毒雾/死亡中毒计入本路火力，不固定补射手；结合剩余血量、敌人速度和实际伤害提前补救，不等墙破。`MutatedChomper` 优先同排坚果后方（更小列号）辅助吞噬，已有嘴仍按威胁补墙。按剩余吞噬容量及当前可用状态判断，不能把吞一只后的消化一概当满载；满载或已无法吞噬时不承担即时救场。
- **布局偏好不能覆盖安全与实际攻击范围。** 葵优先从左往右第4–5列竖种，远程射手优先第1–2列；墙后嘴须够到目标。第5列诡笑葵存在时，同排第6列嘴仍有同化风险：优先保防线，在其他安全行列补葵/放嘴，或有实际保护后再用该格，不为凑布局铲搬有效主力，不假定隔墙必能吞。
- **诡笑葵按实际正前一格避让。** `BloodSunFlower` 同row、column+1的非葵主力危险；第4、5列诡笑葵可同排连种，侧邻/斜邻不一律禁种，恐怖植物不默认免疫。新种/移动主力检查身后葵；新种/移动葵也检查其前方已有主力，不能倒序种植绕过。机枪、糯米天师优先同格套南瓜，细则见参考。
- **安全扩到6–8株，死葵补当前缺额。** 约5株是基础阶段，安全且不占即将防守费用时继续增种；按存活且仍产光的种类计数，不按累计提交数。第4–5列受阻再选安全空位，不必铺满两列；受压先救场，补种费用不能挤掉即将需要的防守。
- **低费过渡，安全时为明确强力目标攒费。** 前期稳经济和防线；能撑过攒费与起效窗口后，按实际费用/冷却为已带强力植物留预算，够费及时种，不反复小额补种花掉升级费，也不无限囤光。受压先有效救场/补防，不空等高费。选卡兼顾过渡与后期，不把高费等同强力。有红光机制的关卡，候选开放就优先带并实际种下 `AlienShooter` 吸红光升级，详见参考；不退局换卡。
- **第32关上两行布局过关即失效。** 后续按全场敌情布阵，详见参考；不把该关下方避种限制推广。
- **红光默认禁收，特殊例外需当前用户授权。** 用户明确授权第40关邻近植物例外时，只选当前collectible_red_sun_ids，过关不沿用。世界x/y和threatened_plant_ids支持提前手套安全避爆，移后正常观察危险是否解除，Committed不当脱险。旧桥接缺字段不猜邻近/半径/倒计时。关闭宽泛auto_collect，普通光仅收 `NormalSun`、`SmallSun`、`TinySun`，未知不收；原生吸收另判，细则见参考。
- **伪人先诱导首攻显形。** `Pseudoman`（对应1–6变体）未首攻前植物攻击打不中；提前在其路径、核心前放/调耐打坚果诱导，不只补射手等它碰经济。种下/接近不等于已首攻，正常后继看攻击、显形或命中变化；不凭共用kind猜变体，不当稳定友军。
- **静止纸人与移动威胁分开。** `Paperman` 不因贴近/高血量触发补墙，纸车、新娘另按机制。尾波只剩纸人时停补葵/养雷，用能命中的持续火力或就绪窝瓜/食人花清场；右射射手打不到同格/身后目标，必要时手套安全腾格。首次倒地会复活召同类，胜利看原生奖励。
- **雷提前准备，成熟未知不能押即时必杀。** `PotatoMine` / `VisceraMine` 有成熟证据且手套就绪才搬到母体可触发位置。0.2.2未暴露VisceraMine成熟字段，ability=null、30秒卡冷却均不能证明武装；无成熟证据先用有效手段，不临敌埋雷或反复空等。
- **传送带积压及时用卡。** 当前可用且有有效合法落点就补防/输出，不为普通卡攒费规则囤特殊卡；救场优先。已Committed不额外空等一轮才用另一张卡；拒绝换新鲜卡或合法格，未知不重放，详见参考。
- 第8关（HorrorStory，chapter_index=0、level_index=7）候选开放就带大嘴花，按参考预留首次接敌费用、逐步补缺防路；不推广到所有关卡。正常后继看存活和伤害，Committed不等于击杀。
