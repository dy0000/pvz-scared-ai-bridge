日期：2026-11-06。范围为本次拆分新增的安装/打包流程及直接受影响的启动器和宿主边界。

| 验证 | 结果 |
| --- | --- |
| `test_install.py` | 6 项通过：无游戏/无交互安装入口、新版文件可安装但须完整、中文/空格/外部路径配置、未准备游戏时生成配置、离线 MCP 握手、源码包排除私有数据 |
| `test_bootstrap.py` | 2 项通过：ZIP 下载入口/解压/参数传递/重复复用；拒绝覆盖无关目录。下载使用本地夹具 |
| `test_launcher.py` | 8 项通过：就绪等待、错误/超时、复用原宿主、外部路径、自动发现并关联已打开游戏、端口所有者和释放阻塞 |
| `test_host.py` | 9 项通过：独占、释放恢复、断线/异常、购买收据持久化和防重放，使用假 Frida 目标 |
| 实际 `install.ps1 -Client Generic -NonInteractive` | 在本机成功准备独立 `.venv` 和 Frida 17.22.1，自动复用已有游戏路径，生成本机配置并列出 32 个 MCP 工具；安装不比较游戏哈希 |

本次没有启动/接管真实游戏，没有修改现有全局 MCP 配置，没有在无 Python 的干净机器上实际运行 winget 安装分支。Codex 自动注册命令格式依据官方文档，未为验证而修改当前用户的服务列表。

原生 JS 与 MCP 动作协议沿用既有 0.2.2；本次未为离线安装拆分重新游玩全关卡。历史实机验证的范围和 assisted 限制见 [compatibility.md](compatibility.md)。
