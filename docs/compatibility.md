# 兼容性与验证范围

## 固定目标

| 项目 | 支持范围 |
| --- | --- |
| 游戏 | Windows x64 PVZ-Scared 1.0.1，具体文件构建绑定 profile.json |
| Unity | 2022.3.62f3 |
| Python | 3.12 x64 |
| Frida | 17.22.1（requirements.txt 固定） |
| 宿主 | Windows，默认 127.0.0.1:47633 |
| 接口 | 0.2.2，32 个 pvzh_* MCP 工具 |
| 模式 | 剧情、图鉴、商店和设置；未接入生存/娱乐 |

四个关键文件为 `PVZ-Scared.exe`、`GameAssembly.dll`、`UnityPlayer.dll`、`PVZ-Scared_Data/il2cpp_data/Metadata/global-metadata.dat`。哈希绑定的是原研究使用的实际文件，不等于作者签名认证，也不表示同版本其他分发包必然兼容。

## 既有实机记录与本次拆分

原桥接的本地历史验收覆盖普通剧情种植、拾取、铲子/手套、奖励续关，以及特殊卡、部分主动能力、Boss 观测、图鉴/设置/金币购买、结局导航。部分后期场景通过显式测试辅助触发，属于 **assisted**；不构成模型自然打通全部关卡的证据。

独立源码包不分发原机器的实机证据、存档或历史授权。其他用户每次开始游玩均以自己的当前授权、构建和现场为准。主菜单 Event 在受支持构建中是“暂未解锁”占位，不能把点击它当作可用模式。

拆分保留 `src/bridge.js`、`src/story.js`、MCP 协议及现有动作规则。新验证针对安装器、路径迁移、宿主边界与源码包隔离，不冒称在干净机器上完成了全流程实机验收。仓库当前定向验证结果见 [verification.md](verification.md)。

## 已知限制

- 地址表绑定具体构建，不自动扫描适配新游戏版本。
- MCP 与 Python 客户端是工具接口；模型、语音朗读和聊天界面由外部客户端提供。
- 图鉴战术是机制参考，不是实时状态。部分成熟、倒计时或免疫信息尚未暴露，不应由 AI 猜测。
- 基础 runner 不覆盖全部关卡的特殊机制。
- Frida 注入可能受系统权限或安全软件策略影响。
